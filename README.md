# 工业质检多模态 Agent 系统

面向蜂窝催化剂产线的缺陷检测与判定 Agent：输入一张端面图像，系统自动完成
**缺陷检测 → 判据检索 → 结论推理 → 结构化报告 → 人工复核**，并全程推送实时进度。

检测模型基于 YOLO11m-OBB 微调（12 类缺陷，旋转框），判定逻辑走**相对化口径**
（缺陷占样品的面积/边长比例），因此不依赖相机的物理标定。

## 目录结构

```
.
├── run.py                      启动入口
├── requirements.txt
├── .env / .env.example         配置（密钥不入库）
├── configs/qc_criteria.yaml    缺陷判据（业务数据，可直接修改）
├── qcagent/
│   ├── settings.py             路径常量唯一真源
│   ├── core/                   检测后端 / 判据库 / 工具 / 事件 / 持久化
│   ├── graph/                  LangGraph 五阶段编排（可选路线）
│   ├── api/                    FastAPI 服务与演示页
│   └── eval/                   分层评测与端到端验收
├── scripts/                    训练与运维脚本
└── data/                       运行态数据（数据库、样本、报告，不入库）
```

**分层依据**：`core` 不依赖任何上层模块；`graph` 与 `api` 依赖 `core`；
`eval` 只依赖 `core`。依赖方向单向，因此每层都能单独导入与测试。

## 快速开始

```bash
pip install -r requirements.txt

# 配置（复制模板后填入 DeepSeek API Key 与检测权重路径）
cp .env.example .env

# 启动服务
python run.py
# 或： uvicorn qcagent.api.app:app --port 8000
```

打开：
- 演示页 <http://127.0.0.1:8000/demo> —— 五阶段进度实时推送
- 接口文档 <http://127.0.0.1:8000/docs>

### 主要接口

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/qc/inspect` | 确定性质检（不经 LLM，直接返回检测结果） |
| POST | `/qc/report` | Agent 端到端，产出结构化报告 |
| GET | `/qc/report/stream` | 同上，SSE 流式推送 |
| GET | `/qc/review/queue` | 待复核队列 |
| POST | `/qc/review/{id}/claim` / `/decide` | 认领 / 提交判定 |
| GET | `/health` | 服务与依赖状态 |
| GET | `/graph/*` | LangGraph 路线（未安装 langgraph 时返回 501） |

## 评测与验证

```bash
# 工具层（确定性，不需要 LLM、不需要 GPU）
python -m qcagent.eval.runner --tool-only

# Agent 层（走 HTTP，需要服务在跑，会消耗 token）
python -m qcagent.eval.runner

# 端到端验收（四条主链路共 17 项检查）
python -m qcagent.eval.acceptance

# 检测指标（需要真实数据集）
python -m qcagent.eval.detect --weights <path/to/best.pt>
```

**分层设计**：工具层用例固定走像素后端（合成图形，结果确定、与模型无关），
真实模型质量由 `qcagent.eval.detect` 在真实数据上单独评测。
两者混在一套用例里，一次模型换代就会让期望值全部失配——这个坑本项目确实踩过。

## 判定逻辑：三处设防挡住"静默放行"

工业判定最危险的不是"检测漏了"，而是**"没读到图像却判了合格"**：

1. **工具层**：固定前缀区分「检测完成 / 检测失败」，调用模型前做图像解码预检
2. **提示词层**：禁止把工具失败当作无缺陷，要求结论填「无法判定」
3. **schema 层**：结论枚举必须含「无法判定」，否则模型只能从允许值里挑、语义静默跑偏

## 已知局限

| 局限 | 说明 |
|---|---|
| 端面裂纹召回偏低 | 35.2%。细长目标，真值长边中位 391 px，缩到 640 后仅约 45 px |
| 小样本类别不稳定 | 孔洞 2、表皮缺口 2、缺角 4、损坏 1 个验证实例，指标不可单独引用 |
| 物理尺寸未标定 | 相机 GSD 未知，故判定走相对化口径，`mm²` 仅作参考 |
| 判据未全覆盖 | 12 类中 11 类已录入；「损坏」类原始文档无文字定义，留空待补 |
